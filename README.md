# Money Machine

An experimental quantitative research and AI decision-support system.

## Objective

Build an evidence-driven system that can:

1. ingest market data
2. validate data quality
3. generate quantitative features
4. test trading hypotheses
5. backtest strategies
6. evaluate risk
7. detect failure modes
8. use AI for research and reasoning
9. challenge its own conclusions
10. produce auditable trade proposals

## Core Principle

The system must optimize for robust, risk-adjusted,
evidence-based decisions rather than prediction accuracy alone.

## Development Rule

No real-money execution during development.

Every strategy must pass:

- data validation
- backtesting
- out-of-sample testing
- robustness testing
- risk evaluation
- paper trading

before real capital is considered.
