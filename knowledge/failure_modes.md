# FAILURE MODES

The system must actively search for these failure modes.

## Data

- Missing data
- Incorrect data
- Duplicate data
- Stale data
- Timestamp errors
- Corporate-action errors
- Survivorship bias
- Look-ahead bias
- Data leakage

## Statistical

- Overfitting
- Selection bias
- Small sample size
- Multiple testing
- Spurious correlation
- Non-stationarity
- Distribution shift
- Regime change

## Strategy

- Unrealistic assumptions
- Excessive turnover
- Hidden transaction costs
- Excessive leverage
- Poor liquidity
- Parameter sensitivity

## AI

- Hallucination
- Fabricated evidence
- False confidence
- Instruction injection
- Prompt injection
- Confirmation bias
- Persuasive but unsupported reasoning

## Execution

- Slippage
- Partial fills
- Order rejection
- API failure
- Network failure
- Duplicate orders
- Stale state

## Risk

- Excessive concentration
- Correlated positions
- Excessive drawdown
- Tail events
- Liquidity collapse
- Unexpected volatility

## Core Rule

A strategy is not considered robust merely because
its historical backtest is profitable.
